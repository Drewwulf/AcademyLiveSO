# Система контролю відвідування занять у школі

## Опис

Система призначена для обліку та контролю відвідування занять учнями школи. Основна особливість системи — робота з мікрогрупами, у яких навчається до 3 учнів.

Система дозволяє керувати інформацією про учнів, мікрогрупи та розклад занять, а також фіксувати відвідування кожного заняття та переглядати історію відвідувань.

## Потенційні ролі користувачів

* **Адміністратор** — керує учнями, мікрогрупами, розкладом та обліковими записами.
* **Викладач** — переглядає свої заняття та відмічає відвідування учнів.
* **Учень** — переглядає свої заняття та історію власних відвідувань.
* **Батьки  — потенційно можуть переглядати розклад та інформацію про відвідування дитини.

## Основні можливості

* Облік учнів.
* Формування мікрогруп до 3 учнів.
* Керування розкладом занять.
* Фіксація відвідування.
* Перегляд історії відвідувань.
* Розмежування доступу відповідно до ролі користувача.

# School Attendance Management System

## Description

The system is designed to track and manage student attendance at a school. Its main feature is support for small study groups of up to 3 students.

The system allows users to manage students, small groups, and class schedules, as well as record attendance for each lesson and view attendance history.

## Potential User Roles

* **Administrator** — manages students, groups, schedules, and user accounts.
* **Teacher** — views scheduled lessons and records student attendance.
* **Student** — views their lessons and attendance history.
* **Parent / Guardian** — can potentially view their child's schedule and attendance information.

## Main Features

* Student management.
* Small group management (up to 3 students).
* Class schedule management.
* Attendance tracking.
* Attendance history.
* Role-based access control.
